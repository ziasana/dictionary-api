# 📘 Dictionary / Vocabulary API (Redis-Enabled)

A fast and cache-optimized **Spring Boot REST API** for managing vocabulary words, now backed by **Redis** for distributed caching.  

This version replaces in-memory caching with a **modern, non-deprecated Redis JSON serializer**, ensuring performance and persistence across multiple instances.

## 🚀 Features

- **CRUD operations** for vocabulary words  
- **MongoDB** integration (Spring Data)  
- **Distributed caching with Redis** (`@Cacheable`, `@CacheEvict`)  
- Non-deprecated **Spring Data Redis JSON serializer**  
- Swagger/OpenAPI 3 documentation  
- Lightweight & production-ready structure  
- Optional Docker setup for Redis + MongoDB  

## 🧱 Tech Stack

- Java 17+  
- Spring Boot 3.2+  
- Spring Data MongoDB  
- Spring Data Redis (Lettuce client)  
- Swagger / OpenAPI 3  
- Docker (optional)

## 📝 API Endpoints

### Get all words
```
GET /api/words
```

### Get a word (cached via Redis)
```
GET /api/words/{word}
```

### Create a new word
```
POST /api/words
Content-Type: application/json
```
Example body:
```json
{
  "word": "Hund",
  "meaning": "Dog",
  "example": "Der Hund spielt im Garten.",
  "synonyms": "Hündchen, Köter"
}
```

### Update a word
```
PUT /api/words/{word}
```

### Delete a word
```
DELETE /api/words/{word}
```

## ⚡ Redis Caching

- Redis is used as the distributed cache backend  
- Cached using `RedisSerializer.json()` (Spring Data Redis 4.x, non-deprecated)  
- Keys are automatically generated by Spring Cache (`spring:cache:<cacheName>::<key>`)

Example in `WordService`:

```java
@Cacheable(value = "wordCache", key = "#word", unless="#result == null")
public Word findByWord(String word) { ... }

@CacheEvict(value = "wordCache", key = "#word.word")
public Word update(Word word) { ... }
```

## 🔧 Configuration (`application.yml`)

```yaml
spring:
  data:
    mongodb:
      uri: mongodb://localhost:27017/dictionarydb
  redis:
    host: localhost
    port: 6379
    timeout: 3000ms
```

## 🐳 Docker (Optional)

```yaml
version: '3.8'
services:
  mongodb:
    image: mongo:6.0
    ports:
      - "27017:27017"
    volumes:
      - mongo_data:/data/db

  redis:
    image: redis:7.0
    ports:
      - "6379:6379"
    command: ["redis-server", "--save", "", "--appendonly", "no"]

volumes:
  mongo_data:
```
Run services:
```bash
docker-compose up -d
```
